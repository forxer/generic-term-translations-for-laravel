## Project Overview

Laravel translation package providing generic term translations (actions, errors, status, units, etc.) through the **Laravel Lang Publisher** plugin system. This is a Composer library, not a Laravel application.

## Key Commands

```bash
# Install/update dependencies
composer update

# Sync source files to locale JSON files
php vendor/bin/lang sync

# Regenerate GLOSSARY.md from source files
php generate-glossary

# Format code
./vendor/bin/pint
```

## Architecture

**Translation flow:** Source PHP files → Laravel Lang Publisher sync → Compiled JSON locale files

- `source/*.php` — Translation definitions as PHP arrays (English as base). **Edit these to add/modify terms.**
- `locales/{locale}/php.json` — Compiled JSON translations per locale. Generated by `lang sync` but French translations are manually maintained here.
- `src/ServiceProvider.php` → `src/Plugin.php` → `src/Plugins/Main.php` — Laravel Lang Publisher integration (maps source files to locale paths).

## Translation Conventions

- Keys use `snake_case`, organized by domain (action, status, error, etc.)
- Parameterized strings use `:parameter` placeholders (e.g., `'add_something' => 'add :something'`)
- Feminine variants use `_fem` suffix (e.g., `all` / `all_fem`)
- French translations require proper Unicode typography:
  - Typographic apostrophe `'` (U+2019), never ASCII `'`
  - Non-breaking space (U+00A0) before `: ? ! ;` and around `« »`
  - Never use `&nbsp;` HTML entities
